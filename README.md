# CONTENT STUDIO

브라우저에서 **대본 → 타이밍 → 이미지 → 편집·저장** 순서로 작업하는 영상 편집기입니다. 음성과 자막은 필요할 때 추가합니다.
대본을 직접 작성하거나 파일 자료를 브라우저에서 읽어 편집할 수 있으며, 이 단계에는 API 키가 필요하지 않습니다.
‘AI 대본 작성’은 참고자료와 정리 방향을 분석하고 웹에서 확인해 새로운 한국어 내레이션 대본을 작성합니다. 보이스 API는 필요하지 않습니다.
작성한 대본은 CLOVA Voice API로 한국어 내레이션을 만들거나 직접 준비한 MP3·WAV와 연결할 수 있습니다.
기본 이미지·음성·영상 편집은 로컬에서 처리합니다.
이미지는 먼저 전환 간격과 시간표를 확정한 뒤 각 구간의 대본·고정 레퍼런스로 생성합니다. 한 장만 직접 만드는 도구도 제공합니다.
‘음성 분석 · 자동 자막’에서는 넣어 둔 내레이션을 인식해 실제 발화 시간에 맞는 자막을 만듭니다.
분야별 작업 탭으로 대본·자료·미디어를 따로 보관합니다. 기본 분야 외에도 원하는 이름의 분야를 추가할 수 있습니다.

소스 저장소: https://github.com/battlebuild001/image-studio

## 제작 관리

상단 **제작 관리**에서 다음 기능을 사용할 수 있습니다. 화면 자막과 읽을
대본은 따로 저장하며, 기존 프로젝트도 그대로 열 수 있습니다.

| 기능 | 사용 방법 |
| --- | --- |
| 자막·음성 대본 분리 | 화면에는 `1991년`, 음성에는 `일구구일년`처럼 각각 편집하고 저장합니다. |
| 발음 사전 | 고유명사·약어의 읽는 방법을 등록하고 미리 본 뒤 음성 대본에 적용합니다. |
| 변경 구간만 재생성 | 기준본과 다른 장면을 확인하고, 해당 이미지 또는 선택한 음성 구간만 생성합니다. 결과는 미리 보고 적용합니다. |
| 예상 비용·예산 | 단가와 환율을 직접 설정해 예상 비용을 확인하고, 설정한 예상 예산을 넘는 새 요청을 차단합니다. |
| 버전 비교·복원 | 대본과 이미지·음성 버전을 보관하고 비교하거나 복원합니다. 이전 미디어도 프로젝트에 유지합니다. |
| 이미지 검수 | 실제 장면 이미지와 레퍼런스를 AI에 보내 대본·전체 컨셉과 맞는지 검수하고 수정할 장면으로 이동합니다. |
| 정보 화면 | 연표·관계도·차트·개념지도를 생성하거나 직접 편집하고, PNG 저장 또는 영상 장면으로 추가합니다. |
| 채널 프리셋 | 채널별 말투·발음·화면 설정과 인트로·아웃트로를 저장해 재사용합니다. |
| 쇼츠 | 원본의 실제 구간을 골라 30초·60초 목표의 별도 세로 프로젝트로 만듭니다. 이미지·자막·음성도 해당 구간에 맞춰 가져옵니다. |
| 게시 자료 | 제목·설명·챕터·태그와 썸네일 후보 세 장을 만들고, 실제 PNG 및 ZIP으로 저장합니다. |

부분 음성 교체는 사용자가 확인한 기존 시간 범위를 실제 합성 음성으로
교체하고 측정한 길이 차이만큼 뒤의 장면·자막을 이동합니다. 대본에서 원래
문장을 확실히 찾을 수 없는 경우에는 전체 대본의 수동 확인을 표시합니다.
쇼츠 생성 전 원본은 보관함에 보존합니다. 원본이 목표 시간보다 짧으면
가능한 구간만 가져옵니다. 지도는 실제 지리 정보가 아닌 개념도입니다.

비용 표의 초기 단가는 수정 가능한 계산 예시이며 공급자의 실제 청구액이나
계정 한도를 조회하지 않습니다. 실패·취소한 요청도 비용이 발생할 수 있어
사용 내역에 남깁니다. 실행 취소로 이미 요청한 비용 추정 내역이 사라지지
않습니다. 새 쇼츠 프로젝트는 별도 내역으로 시작합니다.

AI 작업은 해당 실행 버튼을 누를 때만 요청합니다. 이미지 검수도 유료 API
사용량을 발생시킬 수 있습니다. 발음 사전·직접 정보 화면 편집·프리셋·버전
관리·수동 게시 자료 작성에는 API가 필요하지 않습니다. 음성 합성은 설정된
음성 서버가 필요하며, 게시 자료를 저장해도 외부 채널에 자동 업로드하지
않습니다. API 키와 접속 코드는 프로젝트·백업·버전에 포함하지 않습니다.

새 기능의 브라우저 검증 명령은 `test:production-speech-browser`,
`test:production-changes-browser`, `test:production-budget-browser`,
`test:production-visual-browser`, `test:production-delivery-browser`,
`test:production-guards-browser`입니다. 먼저 `npm start`로 앱을 실행합니다.
테스트는 합성 미디어와 가짜 공급자 응답을 사용하며 실제 모델 품질이나
현재 요금을 검증하지 않습니다.

## 앱 설정에서 OpenAI API 연결

대본 작성·레퍼런스 이미지 생성·내레이션 음성 인식은 **Render 계정이나 별도 API 서버 없이** 사용할 수 있습니다.

1. [웹 편집기](https://battlebuild001.github.io/image-studio/)의 상단 **설정 → OpenAI API**를 엽니다.
2. 본인의 OpenAI API 키를 비밀번호 입력란에 넣습니다. 대본·이미지·음성 인식에 같은 키를 사용합니다.
3. 대본 모델은 `gpt-5-mini`, 이미지 모델은 `gpt-image-2`, 시간 정보가 필요한 음성 인식은 `whisper-1`을 기본으로 사용합니다.
4. 연결을 확인하거나 설정을 저장합니다. 연결 확인은 과금 없는 `GET /v1/models` 요청이며 대본·이미지·음성을 생성하지 않습니다.
   모델 목록 읽기 권한이 제한된 키는 확인이 실패해도 확인 없이 저장할 수 있습니다. 실제 생성 권한과 결제·사용 한도는 해당 작업에서 확인합니다.
5. 대본 작성, 이미지 생성 또는 음성 분석 화면에서 실행 버튼을 누릅니다. 설정 저장만으로 자료를 보내거나 유료 작업을 시작하지 않습니다.

키 보관 방식은 설정에서 선택하고 저장합니다. **이 브라우저에서 계속 기억하기**를 직접 선택하면 전용 `localStorage` 항목에 키와 모델 설정을 보관해 탭이나 브라우저를 다시 열어도 사용합니다.
**이 탭을 사용하는 동안 키 기억하기**는 `sessionStorage`에 보관해 같은 탭의 새로고침까지만 유지합니다. 기본값인 **저장하지 않기**는 현재 페이지 메모리에만 보관하므로 새로고침하면 다시 입력해야 합니다.
브라우저 보관은 이 기기에 키를 저장하므로 공용 기기에서는 사용하지 마세요. 다른 브라우저·기기에는 동기화하지 않으며 사이트 데이터 삭제 후에는 다시 입력해야 합니다.
키 입력란은 저장 후 항상 비워 두고, 입력란 위에 실제 키 저장 여부와 보관 방식을 표시합니다. 빈칸으로 저장해도 기존 키를 유지합니다. 키 삭제는 모든 보관 값과 입력란을 비우고 이전 연결의 진행 중 요청을 취소합니다.
키를 프로젝트·보관함·백업·Git·로그에 넣지 않습니다. 키는 선택한 작업에 필요한 고정 HTTPS 주소 `api.openai.com`으로만 전송하며
다른 서버 주소나 리디렉션으로 전달하지 않습니다. API 사용료는 OpenAI 계정에 청구됩니다. 이 기능은 ChatGPT 구독이나 Codex 채팅을 직접 호출하지 않습니다.

CLOVA Voice 음성 합성은 브라우저 직접 연결을 제공하지 않습니다. 필요한 경우 **설정**의 고급 서버 연결에서 인증된 백엔드를 연결하고
CLOVA 키를 서버에 설정합니다. 준비한 MP3·WAV를 가져오는 방법도 사용할 수 있습니다. [선택적 서버 배포 안내](docs/AI_SERVER_DEPLOY.md)를 참고하세요.

## 주제만으로 자료 수집과 대본 작성

**대본 → 주제만으로 시작하기**에서 원하는 주제를 입력합니다. 파일을 준비하지 않아도 됩니다.
목표 분량과 정리 방향을 정한 뒤 **자료 찾고 대본 쓰기**를 누르면 OpenAI가 웹을 검색해 참고자료를 정리하고, 그 자료로 한국어 내레이션 대본을 이어서 작성합니다.
**자료만 찾기**로 조사 결과를 먼저 확인하고 대본을 나중에 작성할 수도 있습니다. 본인 API 설정에 따라 자료 수집과 대본 작성에 각각 사용료가 발생할 수 있습니다.

앱 안에서 조사 요약·사건과 용어·참고 출처·확인이 필요한 부분을 확인할 수 있습니다. 직접 넣은 자료와 기존 대본은 유지하며,
수집 자료는 별도로 저장합니다. 출처 주소와 조사 메모는 읽을 대본에 넣지 않습니다. 새 주제나 정리 방향으로 바꾸면 이전 수집 결과가 새 조사로 간주되지 않도록 구분합니다.
실제 웹 검색 완료와 검색 출처를 확인하지 못한 응답은 적용하지 않습니다. 결과의 정확성·최신성은 제공자의 검색 품질에 따릅니다.

수집한 시각적 설정은 타이밍 확정 시 전체 이미지의 공통 콘셉트로 이어집니다. 이미 지정한 콘셉트는 유지합니다.
외부 이미지를 자동 다운로드한 결과가 아닌 **이미지 제작 방향**이며, 기준 이미지가 없어도 전체 대본과 이 콘셉트로 모든 장면 이미지를 생성할 수 있습니다.
장면 개수와 생성 요청은 기존 이미지 화면에서 확인하고 시작합니다. 주제 입력·자료 수집·대본 작성만으로 이미지를 생성하지 않습니다.

영상 하단에 안내 문구를 넣으려면 **영상·자막 스타일 → AI 생성 이미지 안내**를 켭니다.
표시할 때 나타나는 **안내 위치**에서 **하단 중앙**, **좌측 하단**, **우측 하단**을 선택할 수 있습니다. 기존 프로젝트의 선택 위치는 유지합니다.
“해당 이미지는 이해를 돕기위한 ai 생성 이미지입니다. 본 원작과는 관련이 없습니다.”가 작게 표시되며,
미리보기·현재 화면 PNG·내보낸 영상에 함께 포함됩니다. 자막 표시와 영상 제목 표시를 꺼도 안내는 별도로 유지됩니다.
처음에는 꺼져 있으며 설정은 프로젝트·백업에 저장됩니다.
영상에 고정 채널명은 자동으로 넣지 않습니다. **영상 제목 표시**는 직접 정한 프로젝트 제목만 표시하며, 인트로·아웃트로에도 사용자가 입력한 제목·보조 문구·로고만 넣습니다.

## 실행 및 개발

Node.js 22 이상을 사용합니다. 프록시를 사용하는 클라우드 환경에서는 Node.js 24.5 이상이 필요합니다.
서버와 테스트에 필요한 패키지를 설치한 뒤 실행합니다. 별도 빌드는 없습니다.
직접 대본 작성, 파일 텍스트 추출, 기본 영상 편집과 고정 레퍼런스 관리에는 API 키가 필요하지 않습니다.
브라우저용 문서 추출 라이브러리는 `dist/vendor/`에 고정 버전으로 포함하며 외부 CDN에서 가져오지 않습니다.

```bash
git clone https://github.com/battlebuild001/image-studio.git
cd image-studio
npm ci
npm start
```

브라우저에서 http://127.0.0.1:4173/ 을 엽니다. `index.html`을 파일로 직접
여는 대신 이 서버를 사용합니다. 정적 파일은 `dist/`만 제공합니다. **OpenAI API 직접 연결** 모드는 브라우저에서 제공자에 요청하며,
선택적인 서버 연결 모드에서는 `/api/script/*`, `/api/voice/*`, `/api/image/*`, `/api/transcript/*` 요청을 Node 서버가 처리합니다.

```bash
npm test
```

Playwright와 Chromium이 설치된 개발 환경에서는 서버를 켠 상태로
`npm run test:browser`를 실행해 실제 편집·저장·복원·영상 출력을 검증합니다.
이 클라우드 환경에는 두 도구가 준비되어 있습니다. 기본 서버는 4173 포트이며,
다른 주소는 `STUDIO_URL`로 지정합니다. 합성 미디어만 사용하고 검증 산출물은 `/tmp`에 저장합니다.
대본 제작 화면의 별도 브라우저 회귀 검증은 `npm run test:script-browser`,
레퍼런스 이미지 화면은 `npm run test:image-browser`,
음성 자막 화면은 `npm run test:transcript-browser`,
대본·음성 제작 흐름은 `npm run test:voice-browser`로 실행합니다.
분야 탭의 별도 브라우저 회귀 검증은 `npm run test:workspace-browser`입니다.
접힌 도구, 프로젝트 메뉴와 키보드 탐색은 `npm run test:layout-browser`로 검증합니다.
이미지 움직임·화면 효과와 실제 영상 출력은 `npm run test:scene-effects-browser`로 검증합니다. 이 개발 검증에는 `ffprobe`도 필요하며, 웹앱 실행에는 필요하지 않습니다.
작업 진행 표시와 취소는 `npm run test:operation-browser`, 보관함·분야 작업의 진행·실패 보존은
`npm run test:local-operations-browser`로 검증합니다. 지연·오류를 제어하는 검사는 실제 유료 요청을 하지 않습니다.
전체 영상 이미지 구성·일괄 생성·부분 완료와 직접 연결은 `npm run test:whole-video-browser`로 검증합니다.
원본 반영·설명 상세도·길이 늘리기와 저장 호환성은 `npm run test:script-fidelity-browser`로 검증합니다.
타이밍 미리보기는 `npm run test:scene-timing-browser`, 확정된 장면의 순차 생성은 `npm run test:scene-batch-browser`,
전체 타이밍·보관·생성 흐름은 `npm run test:timed-workflow-browser`로 검증합니다. 이 생성 검사는 실제 유료 요청 대신 모의 응답을 사용합니다.
인증키가 없는 테스트에서는 생성 응답을 명시적인 모의 자료로 검증합니다.
음성 자막 테스트도 실제 WAV 바이트와 모의 발화 시간을 사용합니다.
실제 대본 작성 품질, 레퍼런스 이미지의 재현도, 한국어 음성 인식 정확도나 CLOVA 음성 품질을 검증한 것으로 취급하지 않습니다.

다른 호스트나 포트가 필요할 때:

```bash
npm start -- --host 0.0.0.0 --port 4173
```

외부 주소로 실행할 때는 서버 환경에 24자 이상의 별도 `STUDIO_ACCESS_TOKEN`을 먼저 설정해야 합니다.
비밀 값은 배포 서비스의 환경 설정에서 입력합니다. 기본 루프백 실행에는 접속코드가 필요하지 않습니다.

## Codex에서 이어서 작업하기

이 저장소를 Codex 프로젝트 또는 클라우드 환경에서 선택하고 `main` 브랜치를

  순서로 사용합니다. 기존 플랫폼 인증을 우선 확인하고, 별도 토큰이 필요하면
  환경 설정에서 해당 저장소의 Contents·Pages 쓰기 권한이 있는 값을 연결합니다.

- `api.github.com`과 GitHub API가 반환하는 공개 Pages 도메인 접근이 필요합니다.
  이 저장소의 기본 Pages 도메인은 `battlebuild001.github.io`입니다.
  네트워크 정책·인증·Pages 플랜이 허용되지 않으면 CLI가 배포를 완료할 수 없습니다.

## 사용 흐름

상단에서 작업할 분야를 고른 뒤 진행합니다. 각 분야는 마지막 작업 상태를 따로 저장합니다.

1. **대본**: 참고자료·정리 방향·목표 분량을 넣고 AI가 한국어 내레이션으로 새로 작성하게 합니다. 직접 쓴 대본도 편집할 수 있습니다.
2. **타이밍**: 이미지가 몇 초마다 바뀔지 정하고 시간표·장면 수를 확인해 확정합니다. 이 단계에서는 이미지를 생성하지 않습니다.
3. **이미지**: 각 구간의 요청·레퍼런스·생성 장수를 검토한 뒤 이미지 생성을 시작하거나 준비한 이미지를 가져옵니다.
4. **편집·저장**: 장면·자막을 다듬고 미리보기에서 확인한 뒤 MP4 또는 WebM으로 내보냅니다. 형식은 브라우저가 실제로 지원하는 것만 선택할 수 있습니다.

음성은 필수 단계가 아닙니다. 미리보기 아래 **음성·자막**을 열면 CLOVA 음성 생성, MP3·WAV 가져오기, BGM, 음성 분석과 SRT 도구를 사용할 수 있습니다. 실제 내레이션을 추가한 뒤에는 그 길이에 맞춰 타이밍을 다시 확인할 수 있습니다.

자주 쓰지 않는 도구는 필요할 때 펼칩니다.

- 상단 **프로젝트**: 새 프로젝트·열기·백업·보관함·사용법·예시. API 연결용 **설정**과 **영상 내보내기**는 상단에 계속 표시됩니다.
- 왼쪽 **제작 도구**: 수동 대본·한 장씩 레퍼런스 이미지 제작·제목 템플릿·PNG 저장.
- 왼쪽 **선택 장면 편집**: 여러 장면 선택·복제·분할·일괄 편집.
- 장면 설정의 **움직임·장면 도구**: 화면 움직임·맞춤·구도·장면 순서.
- 미리보기 아래 **영상·자막 스타일**: 화면 전환과 전체 자막 스타일.

접힌 도구를 여는 것만으로 API 요청이나 이미지 생성이 시작되지 않습니다. 이미지 일괄 생성의 장수·비용 안내·확인란은 생성 화면에서 계속 확인해야 합니다. 도구의 펼침 상태는 현재 페이지 메모리에만 유지하며, 프로젝트·백업에 저장하지 않습니다.

## 이미지 전환 간격과 장면 생성

장면 패널의 숫자는 **현재 장면 슬롯 수**입니다. 예를 들어 이전 작업에 `157`이 표시되어도 AI가 이미지를 157장 생성했다는 뜻은 아니며, 이미지가 비어 있는 자리도 포함됩니다. 기존 프로젝트를 열거나 새 버전으로 바꾸는 것만으로 장면을 다시 나누거나 이미지를 생성하지 않습니다.

1. 상단 **타이밍** 또는 완성한 대본의 장면 만들기를 엽니다.
2. **이미지 전환 간격**에 몇 초마다 이미지를 바꿀지 입력합니다. 기본값은 **10초**이며, 1~600초 사이에서 정합니다. 총 길이가 8분이면 10초 간격은 **48장**, 20초 간격은 **24장**입니다. 문장·문단 개수로 장면 수를 자동 결정하지 않습니다.
3. 전체 길이, 장면 수, 각 장면의 시작·종료 시각과 대본·이미지 요청을 미리 확인합니다. 목표 길이를 직접 정하거나 실제 내레이션 길이를 우선 사용할 수 있습니다. 음성이 없으면 현재 영상 길이 또는 대본의 예상 길이를 사용합니다. 마지막 장면은 남은 길이에 맞춥니다.
4. **타이밍 확정 · 장면 만들기**를 눌러 시간표를 적용합니다. 미리보기와 취소는 현재 작업을 바꾸지 않습니다. 기존 장면을 다시 나누기 전에는 원본 프로젝트와 미디어를 보관함에 저장합니다. 확정은 시간표와 이미지가 들어갈 자리를 만드는 작업이며 **이미지 API를 호출하지 않습니다**.
5. **영상 전체 이미지 만들기**을 열어 시간 구간별 이미지 요청을 다듬고, 고정 레퍼런스·배경·화풍·품질·이번 생성 장수를 확인합니다. 이미 이미지가 있는 장면은 기본적으로 유지합니다. 교체하려면 **이미지가 있는 장면도 새로 생성해 교체하기**를 직접 선택합니다.
6. 타이밍·요청·레퍼런스·장수 확인란을 선택한 뒤 **생성 시작**을 누릅니다. 이때부터 장면마다 이미지 API 요청이 순서대로 실행되므로 사용료가 발생할 수 있습니다. 각 결과는 확인한 시작·종료 시각의 기존 장면에 들어가며, 이미지 생성으로 장면 수나 시간을 다시 바꾸지 않습니다.

생성을 중지하거나 일부 요청이 실패하면 완료한 이미지는 유지하고 이후 요청을 멈춥니다. 자동 유료 재시도나 자동 재개는 하지 않습니다. 다시 진행하려면 남은 장면과 옵션을 확인하고 명시적으로 시작합니다. 기본 유지 옵션에서는 이미 채운 장면을 건너뜁니다.

프로젝트는 최대 **200개 장면**을 지원합니다. 선택한 간격으로 이를 넘으면 간격을 늘리라는 안내를 표시하며, 프로그램이 임의로 간격이나 이미지 수를 바꾸지 않습니다. 대본·장면 순서·시간·내레이션이나 자르기 범위가 바뀌어 확정한 계획과 달라지면 타이밍을 다시 확인·확정해야 합니다.

대본과 일치하는 음성 분석·SRT가 있고 선택한 길이에 들어오면 실제 자막 시각으로 대본 구간을 배치합니다. 그 외의 대본 배치는 글자 수에 따른 추정이며 실제 음성 인식으로 표시하지 않습니다. 일치하는 기존 음성 분석·SRT의 자막 시각은 장면 분할만으로 덮어쓰지 않습니다.

확정한 계획은 선택적 `project.scenePlan`에 저장되며 자동 저장·보관함·파일 포함 백업으로 이어집니다. 기존 버전의 프로젝트 형식과 호환되고, 이전 작업에 새 계획을 자동으로 생성하지 않습니다. **고정 레퍼런스·한 컷 만들기**의 한 장 생성·미리보기·직접 적용도 계속 사용할 수 있습니다.

## 분야별 작업 탭

처음에는 **블랙아웃·사만·에오지·데이터 분석** 탭을 제공합니다. **+ 분야 추가**에서 원하는 이름을
입력해 새 작업 공간을 만듭니다. 분야 이름은 1~40자이며 보관한 분야를 포함해 최대 50개까지 관리합니다.
**분야 관리**에서 이름·순서를 바꾸고, 탭을 보관하거나 다시 열 수 있습니다. 보관은 삭제가 아니므로
작업 내용이 남으며, 마지막 열린 분야는 보관할 수 없습니다.

각 분야의 현재 프로젝트, 직접 쓴 대본, 조사 자료·출처, 고정 레퍼런스, 장면 이미지, 내레이션,
BGM, 장면·자막·편집 설정은 서로 따로 저장합니다. 탭을 전환하기 전에 현재 입력과 프로젝트를 저장하고
다음 작업의 미디어를 읽습니다. 저장이나 불러오기가 실패하면 현재 작업을 유지합니다.
기존 버전의 자동 저장 작업은 새 버전의 첫 실행 시 **블랙아웃** 분야로 옮겨 보존합니다.
되돌리기·다시 실행 기록은 분야를 전환하면 초기화되며 다른 분야의 편집으로 넘어가지 않습니다.

프로젝트 보관함과 자막 스타일·제목 템플릿 프리셋은 브라우저 전체에서 공유합니다.
다른 분야의 현재 작업을 자동으로 섞지 않으며, 보관함의 프로젝트는 직접 열어 재사용할 수 있습니다.
영상 내보내기와 파일 포함 프로젝트 백업은 **현재 선택한 분야의 프로젝트**에 적용됩니다.
프로젝트 백업 형식은 기존 버전과 같으며 분야 탭 목록 전체를 내보내는 기능은 아닙니다.

분야와 보관한 탭은 이 브라우저의 IndexedDB에 저장하며 기기 간 동기화하지 않습니다.
브라우저 데이터를 지우면 작업·분야 목록도 없어지므로 중요한 프로젝트는 파일 포함 백업으로 보관하세요.
분야 이름은 작업 분류와 제작 요청문의 맥락에 사용합니다. **데이터 분석**도 기존 제작 도구를 따로
정리하는 분야이며 통계 계산이나 데이터 분석 엔진을 추가한 것은 아닙니다.

## 영상 전체 이미지 만들기

타이밍을 확정하면 왼쪽 이미지 추가 아래에 **영상 전체 이미지 만들기**가 표시됩니다. 상단 **이미지**에서도 같은 화면을 엽니다. 현재 선택한 한 컷이 아닌 **확정된 전체 시간표**가 대상입니다.

1. **영상 전체의 공통 콘셉트**에 공통 화풍·색감·분위기·외형 기준을 적습니다. 기준 이미지는 선택 사항이며 **레퍼런스·배경 설정**에서 등록할 수 있습니다.
2. **전체 대본으로 이미지 구성 만들기**를 누릅니다. 실제 텍스트 AI가 전체 대본과 모든 구간을 함께 읽고 공통 시각 콘셉트와 컷별 이미지 요청을 만듭니다. 이 작업도 API 사용료가 발생할 수 있으며 아직 이미지는 생성하지 않습니다.
3. 공통 콘셉트와 구간별 요청을 검토합니다. AI 구성에는 전체 대본을 전달하고, 각 이미지 생성에는 그 전체 내용에서 만든 공통 시각 콘셉트·사용자 콘셉트·해당 컷과 앞뒤 장면 맥락을 함께 전달합니다. 장면 요청은 직접 고칠 수 있습니다.
4. **이번 생성 장수**와 비용 안내를 확인하고 확인란을 체크한 뒤 **이미지 생성 시작**을 한 번 누릅니다. 모든 빈 장면을 순서대로 생성하고 각 확정된 컷에 적용·저장합니다. 이미 있는 컷은 기본 유지하며, 전체를 새 콘셉트로 다시 만들려면 **이미지가 있는 장면도 새로 생성해 교체하기**를 선택합니다. 48컷 중 1컷에 이미지가 있으면 기본 생성은 47장, 교체를 선택하면 48장입니다.

구성·생성은 명시적 버튼으로만 시작하며 타이밍 확정·설정 변경·새로고침으로 유료 작업을 시작하지 않습니다. 중지·오류 시 완료한 이미지를 유지하고 새 요청을 멈춥니다. 이어 만들기도 확인 후 직접 시작하며 자동 유료 재시도는 없습니다.
대본·타이밍·공통 콘셉트·배경·화풍·참조가 달라져 AI 구성이 오래되면 재구성을 요구합니다. 타이밍을 다시 정할 때 사용자 공통 콘셉트는 유지하지만 이전 컷 구성은 다시 만들어야 합니다.

참조 이미지가 있으면 실제 파일을 `/images/edits`에 함께 전달합니다. 참조가 없으면 `/images/generations`로 텍스트 기반 이미지를 만듭니다. 참조의 외형은 해당 대상이 등장하는 컷에서 유지하도록 요청하며, 관련 없는 초기 장면까지 군인·무기 등을 억지로 넣도록 하지 않습니다. 세부 외형이나 이야기 적합성이 완벽하다고 보장하지 않으므로 결과를 확인하세요.

이전 수동 장면 요청도 기본 요청 모드로 사용할 수 있습니다. 이 모드는 AI 전체 분석으로 표시하지 않습니다. 전체 AI 구성에는 최대 100,000자의 대본을 한 번에 전달하며, 이미지 요청은 공통 구성과 해당 컷 맥락으로 압축합니다. 전체 이미지 요청이 한도를 넘으면 유료 이미지 호출 전에 줄이라는 안내를 표시합니다.

## 이미지 움직임·효과

장면을 선택하면 **장면 설정 → 이미지 움직임·효과**가 표시됩니다. 생성한 이미지와 직접 가져온 이미지에 모두 사용할 수 있습니다.

- **은은하게 움직이기**: 선택한 장면에 아주 작은 확대와 이동을 번갈아 적용합니다. 여러 장면을 선택해 한 번에 적용할 수 있습니다.
- **화면 효과**: 없음 / 은은한 먼지 / 옅은 안개 / 부드러운 빛. 효과를 고르면 현재 장면에 적용되며 강도는 **0~100%**로 조절합니다. 0%는 효과를 그리지 않습니다.
- 현재 장면의 효과를 정한 뒤 **선택 N개 장면에 효과 적용**을 누르면 선택한 장면에 같은 효과·강도를 적용합니다. **설정 복사·붙이기**에도 움직임과 효과가 포함됩니다.
- 더 자세한 카메라 설정은 **움직임·장면 도구**의 **아주 살짝 확대 / 아주 살짝 이동** 또는 기존 직접 설정으로 조절합니다. 움직임을 없애려면 **고정**, 화면 효과를 없애려면 **없음**을 선택합니다.

정지 이미지에 카메라 움직임과 화면 오버레이를 더하며, 인물이나 사물의 개별 동작을 새로 생성하지 않습니다. 추가 API 호출·생성 비용·미디어 업로드는 없습니다.
미리보기·PNG·최종 영상은 같은 렌더러를 사용합니다. 효과는 장면의 재생 시간에 따라 바뀌고 같은 장면·같은 시각을 다시 보면 같은 모습입니다. 새로 분할된 장면은 자신의 시작 시각부터 효과를 재생합니다.
기존 프로젝트는 효과 없음으로 불러오고 기존 카메라 움직임을 유지합니다. 효과 변경은 되돌리기·자동 저장·분야 탭·보관함·백업에 함께 보존되며, 원본 이미지·장면 시간·자막은 바꾸지 않습니다.

## 작업 진행 표시

대본·이미지·음성 생성, 자막 분석, 파일 처리와 저장·보관 작업은 스피너, 현재 작업과 경과 시간을 표시합니다.
응답이 늦어지면 대기 안내를 추가하며, 완료·오류·취소 결과를 남깁니다. 경과 시간은 서비스가 내부에서 어디까지
처리했는지나 남은 시간을 뜻하지 않습니다. 취소를 지원하는 작업은 취소 버튼으로 중단할 수 있으며,
실패하거나 취소해도 기존 자료와 완료된 결과를 유지합니다. 유료 작업은 자동으로 재시도하지 않습니다.

## 자료로 대본 제작

1. 상단 **대본**을 누릅니다. 오른쪽 대본 편집기는 API 연결 없이도 사용할 수 있습니다.
2. 참고할 텍스트를 붙여넣거나 TXT·MD·PDF·DOCX 파일을 넣습니다. 파일 한 개는
   10MiB 이하, 한 번에 최대 5개·합계 20MiB이며, 합친 자료는 최대 100,000자입니다.
   텍스트를 선택할 수 없는 스캔·이미지 PDF는 OCR로 변환한 뒤 넣어주세요.
3. 목표 분량을 **1~60분**으로 정하고 읽는 속도를 조절합니다. 기본값은 **8분·분당 330자**이며,
   분당 200~500자 범위에서 설정합니다. 글자 수는 공백을 제외해 계산합니다.
4. **정리 방향**에 어조·구성·강조할 내용을 적고 **AI 대본 작성**을 누릅니다. 참고자료를 검색·확인하고 목표 분량에 맞춰 새 한국어 내레이션, 요약, 출처와 확인할 사항을 작성합니다.
   **설정 → OpenAI API**에 본인 키를 입력해 직접 연결하거나, 선택적인 고급 서버 연결을 사용합니다. 보이스 키는 필요하지 않습니다.
   직접 작성도 가능하며, 원문을 그대로 옮기는 기능은 **수동 편집 도구** 안에 따로 있습니다. 이 작업은 AI 생성이 아닙니다.
   오류·취소 시 기존 대본은 유지합니다. 대본은 복사하거나 텍스트 파일로 저장할 수 있습니다.
5. 완성한 대본으로 **타이밍**을 정합니다. 이미지 전환 간격·전체 길이·장면 수를 먼저 미리 보고 **타이밍 확정 · 장면 만들기**를 누릅니다. 장면 수는 문단 개수가 아니라 선택한 시간 간격으로 정하며, 이미지 생성은 이후에 별도로 시작합니다. 음성이 필요하면 **음성·자막**에서 별도로 생성하거나 가져옵니다.

**대본 구성**을 펼치면 원본을 얼마나 담을지와 설명 상세도를 정할 수 있습니다.

- **원본 반영 정도**: 핵심만 요약 / 균형 있게 반영 / 원본 최대한 유지.
- **설명 상세도**: 간결하게 / 보통 / 자세히 설명. 자세히 설명은 자료로 뒷받침되는 배경과 사건의 연결 설명을 늘리며, 원문에 없는 사건·동기·행동·수치를 지어내도록 허용하지 않습니다.
- 새 대본의 기본값은 **원본 최대한 유지 + 자세히 설명**입니다. 기존 저장본에 옵션이 없으면 **균형 있게 반영 + 보통**으로 불러옵니다.
- **목표 길이 1.5배 / 목표 길이 2배**는 현재 목표 분을 실제로 바꿉니다. 8분에서 각각 12분·16분이 되며 최대 60분입니다. 숨겨진 배수를 추가하지 않습니다.

원본 충실 모드에서는 사건·연도·인물·세력·부정 표현과 연표 순서를 보존하도록 요청합니다.
긴 원문에 비해 목표 분량이 짧으면 안내를 표시합니다. 이 안내는 원문 글자 수 비교이며 영어를 한국어로 번역한 실제 길이나 사건 누락 여부를 판정한 결과는 아닙니다.
출력 분량이 목표와 크게 다르면 별도 안내를 표시하며, 추가 유료 요청을 자동 실행하지 않습니다.
설정 변경만으로 현재 대본을 다시 쓰지 않으며 다음 **AI로 대본 작성**에 적용합니다. 옵션은 분야별 저장·보관함·백업에 포함됩니다.

**AI 보이스용 표기**에서 새 AI 대본의 읽는 방식을 선택합니다.

| 옵션 | 숫자·영문 예시 |
| --- | --- |
| 한글 음차 · 숫자를 일구구일로 | `1991` → `일구구일`, `NASA` → `나사` |
| 한글 음차 · 숫자를 하나아홉아홉하나로 | `1991` → `하나아홉아홉하나`, `0` → `공` |
| 한글 음차 · 숫자는 문맥에 맞게 | 연도는 `천구백구십일 년`처럼 읽고 영문 이름은 한글 발음으로 작성 |
| 일반 표기 · 숫자·영문 유지 | 숫자와 영문을 일반 표기로 작성 |

새 대본의 기본값은 **일구구일 방식**이며, 표기 옵션이 없던 기존 저장 대본은 일반 표기로 불러옵니다.
옵션을 선택하는 것만으로 현재 대본을 바꾸지 않습니다. **현재 대본의 숫자·표시 정리**는 선택한 숫자 방식과
주소·인용 표시를 로컬에서 정리합니다. 영문 고유명사의 한글 음차는 **AI로 대본 작성**에서 처리합니다.

대본 편집기, **대본 복사**, **TXT 저장**, 음성·타이밍으로 보내기에는 읽는 내레이션만 사용합니다.
주소, 인용 번호와 검색·검증 과정 설명은 읽는 대본에서 정리하며, 요약·주의사항·실제 출처는 기본으로 접힌
**조사 메모·출처 (읽는 대본과 별도)**에 보관합니다. 별도 **조사 기록 저장**과 프로젝트 백업에는 이 근거를 유지합니다.

예상 길이는 글자 수와 읽는 속도에 따른 **추정치**입니다. 실제 내레이션의 길이를 보장하지 않으며,
완성한 음성 파일을 넣고 장면 시간을 다시 맞출 수 있습니다. 직접 작성한 대본, 입력 자료·목표 분량·생성 결과와 출처는
프로젝트 자동 저장, 보관함과 파일 포함 백업에 함께 보존됩니다.

TXT·MD·PDF·DOCX 텍스트 추출은 브라우저에서 처리하며 원본 문서를 서버나 외부 AI에 업로드하지 않습니다.
**AI 대본 작성 버튼을 눌렀을 때만**
입력 텍스트와 추출한 텍스트를 외부 AI 서비스에 보내 웹 검색·작성을 요청합니다.
편집용 이미지·음성 파일은 이 대본 제작 기능으로 전송하지 않습니다.

키가 연결되지 않았어도 자료 입력·파일 텍스트 추출·목표 분량 계산과 제작 요청문 복사는 사용할 수 있습니다.
실제 웹 검색·대본 생성에는 앱 설정의 OpenAI 직접 연결 또는 아래의 선택적 서버 연결이 필요하며, 사용량에 따른 AI·검색 비용이 발생할 수 있습니다.

## 선택적 대본 제작 서버 설정

OpenAI 직접 연결에는 아래 환경 변수가 필요하지 않습니다. 키를 서버에 보관하는 운영 방식을 선택한 경우에만
[서버 배포·연결 안내](docs/AI_SERVER_DEPLOY.md)를 따릅니다. **설정**의 고급 서버 연결에는 서버 주소와
`STUDIO_ACCESS_TOKEN` 앱 접속코드를 입력하며, 이 모드의 제공자 키는 서버에서 설정합니다. 앱 접속코드는 현재 탭 세션에만 보관하고 프로젝트·백업에 넣지 않습니다.

| 환경 변수 | 용도 |
| --- | --- |
| `SCRIPT_AI_API_KEY` | 서버에서 사용하는 OpenAI API 키. 환경 설정의 비밀 값으로 등록합니다. |
| `SCRIPT_AI_MODEL` | 대본 생성 모델. 기본값 `gpt-5-mini`. 웹 검색 도구를 지원하는 모델을 사용합니다. |

일반 로컬 환경에서는 `OPENAI_API_KEY`도 대체 입력으로 사용할 수 있습니다.
클라우드 환경에서는 `SCRIPT_AI_API_KEY`를 사용하고 `api.openai.com`으로의 HTTPS 접근을 허용합니다.
서버 운영용 키를 브라우저로 반환하거나 정적 파일·프로젝트 백업·Git에 저장하지 않습니다. 개인 직접 연결용 키는 위의 앱 설정에서 별도로 입력합니다.
환경 변수는 서버 프로세스에 주입하며, 바꾼 뒤 서버를 다시 시작합니다.
현재 개발 서버는 `.env` 파일을 자동으로 읽지 않습니다.

키가 없는 환경의 테스트는 파일 추출·분량 계산·저장 복원과 모의 생성 응답을 검증합니다.
실제 웹 검색과 AI 결과의 내용·분량·출처 품질은 키를 연결한 뒤 별도로 확인해야 합니다.

## 대본으로 한국어 음성 만들기

1. 대본을 작성한 뒤 미리보기 아래 **음성·자막**을 열어 **AI 음성 만들기**를 누릅니다. 한국어 화자 **아라(`nara`)**를 사용합니다.
2. 속도·높이·음량을 조절한 뒤 생성 버튼을 누릅니다. 속도는 `-5~10`이며 음수는 빠르게,
   양수는 느리게 읽습니다. 높이와 음량은 각각 `-5~5`입니다.
3. 대본은 최대 **30,000자**이며 요청당 최대 **2,000자**로 나눕니다. 한글이나 이모지의 유니코드 문자를
   중간에서 자르지 않고, 모든 조각을 순서대로 합친 텍스트가 원문과 같도록 보존합니다.
4. 서버가 받은 실제 MP3 조각을 브라우저에서 디코딩해 하나의 모노 24kHz WAV로 합칩니다.
   결과를 미리 듣거나 다운로드하고, **적용**을 눌러 프로젝트 내레이션으로 넣습니다.
   생성만으로 기존 음성을 바꾸지 않으며 취소·실패·오래된 결과가 기존 내레이션을 덮어쓰지 않습니다.

생성 버튼을 눌렀을 때만 작성한 대본과 음성 설정을 서버 및 CLOVA Voice에 전송합니다.
참고 자료 원문, 이미지, 기존 음성 파일은 이 요청에 포함하지 않습니다. 실제 생성에는 CLOVA 사용량에
따른 비용이 발생할 수 있으며, 결과 길이는 생성된 음성의 실제 재생 시간을 기준으로 계산합니다.
API 없이도 직접 준비한 MP3·WAV를 내레이션으로 가져올 수 있습니다.

## CLOVA Voice 서버 설정

| 환경 변수 | 용도 |
| --- | --- |
| `CLOVA_VOICE_CLIENT_ID` | CLOVA Voice Premium 애플리케이션의 서버용 Client ID. |
| `CLOVA_VOICE_CLIENT_SECRET` | 같은 애플리케이션의 서버용 Client Secret. |

음성 생성은 OpenAI용 `SCRIPT_AI_API_KEY`와 별개입니다. 두 값을 브라우저나 프로젝트에 저장하지 말고
서버의 비밀 환경 변수로 연결합니다. 클라우드 환경 설정에는 선택적인 **사용자 제공** 자격 증명으로 등록합니다.
사용하지 않는 키를 필수 항목으로 추가해 기본 환경 게시를 막지 않습니다.
HTTPS 대상은 `naveropenapi.apigw.ntruss.com`이며, 서버는 공식 Premium 경로
`https://naveropenapi.apigw.ntruss.com/tts-premium/v1/tts`를 사용합니다.
연결 확인은 `GET /api/voice/config`, 생성은 `POST /api/voice/generate`입니다.
서버 설정을 바꾸면 프로세스를 다시 시작합니다. 현재 개발 서버는 `.env`를 자동으로 읽지 않습니다.

정적 GitHub Pages에는 이 서버가 없으므로 대본 직접 작성과 음성 파일 가져오기는 사용할 수 있지만
CLOVA API 음성 생성에는 **설정**의 고급 서버 연결로 연결한 Node 백엔드의 CLOVA 키가 필요합니다. OpenAI 직접 연결만으로 CLOVA 합성이 활성화되지는 않습니다.
현재 런타임에는 CLOVA 키가 연결되지 않았습니다. 합성 MP3·WAV와 모의 API 응답으로 요청·병합·적용을
검증하며, 실제 한국어 발음·음질이나 계정별 사용 권한을 검증한 것으로 보고하지 않습니다.

## 고정 레퍼런스로 이미지 제작

대본과 **같은 OpenAI API 설정과 개인 키**로 이미지를 생성합니다. 상단 **설정 → OpenAI API**에 키를 입력하면 Render 없이 직접 연결합니다. 별도 이미지 키는 필요하지 않으며, 계정에 이미지 모델 이용 권한이 있어야 합니다. 키를 서버에 보관하는 운영 방식을 원하는 경우 [선택적 서버 배포 안내](docs/AI_SERVER_DEPLOY.md)를 참고하세요.

1. 왼쪽 **제작 도구 → 고정 레퍼런스·한 컷 만들기**을 엽니다.
2. 배경 설정·세계관, 공통 화풍과 피할 요소를 적습니다. 기준 이미지는 선택 사항입니다.
   PNG·JPG·WebP를 최대 **5장**, 한 장당 **10MiB**, 합계 **20MiB**까지 관리합니다.
   메인 컨셉·배경·캐릭터·화풍·기타 역할과 이름을 붙여 참조 목적을 구분합니다.
3. 이번 장면에서 바꿀 행동·장소·구도를 입력합니다. 사용할 레퍼런스만 켜 두면
   다음 생성에서도 같은 기준 이미지와 설정을 계속 참조합니다.
   기존 장면 이미지를 레퍼런스로 등록해 재사용할 수도 있습니다.
4. 한 장을 직접 만들 때는 **고정 레퍼런스로 1장 생성**을 눌러 결과를 확인합니다. 결과를 PNG로 저장하거나,
   선택 장면에 적용하거나 새 장면으로 추가합니다. 생성만으로 기존 장면을 바꾸지 않습니다.

확정한 시간표 전체의 이미지를 만들려면 앞의 **이미지 전환 간격과 장면 생성** 순서로 진행합니다. 이 도구에서 배경·레퍼런스만 설정해도 이미지를 자동으로 만들지는 않습니다.

배경 설정과 원본 레퍼런스 이미지는 프로젝트 자동 저장·보관함·파일 포함 백업에 함께 보존됩니다.
참조를 잠시 끈 이미지도 저장되며, 장면과 레퍼런스가 같은 이미지를 사용하면 미디어를 중복 저장하지 않습니다.
레퍼런스 전용 프로젝트도 보관할 수 있습니다. 모든 프로젝트 미디어에는 기존 180MiB 한도가 적용됩니다.

기본 편집 중에는 이미지를 외부로 보내지 않습니다. **생성 버튼을 누를 때만** 켜 둔 레퍼런스의
실제 이미지 데이터를 브라우저에서 긴 변 1536px 이하로 조정해 배경 설정·장면 요청과 함께 OpenAI에 전달합니다. 서버 연결 모드를 선택했다면 연결한 서버를 거칩니다. 파일 이름만 전달하는 방식이 아닙니다. 음성이나 다른 편집 이미지는 보내지 않습니다.
요청문 복사는 이미지를 첨부하지 않으므로, 외부 서비스에서 직접 만들 때는 기준 이미지도 함께 첨부하세요.

이미지 생성은 사용량에 따라 비용이 발생할 수 있습니다. 레퍼런스를 참조해도 인물·기체의 세부 표현이나
구도가 완전히 같다고 보장하지 않으며, 실제 결과를 확인한 뒤 적용합니다. 키가 없어도 레퍼런스와 설정을
저장하고 요청문을 준비할 수 있습니다. 모의 응답 테스트는 실제 이미지 품질 검증과 구분합니다.

## 선택적 레퍼런스 이미지 서버 설정

개인 OpenAI 직접 연결에서는 앱 설정의 이미지 모델과 키를 사용하므로 아래 서버 환경 변수가 필요하지 않습니다.

| 환경 변수 | 용도 |
| --- | --- |
| `IMAGE_AI_MODEL` | 이미지 편집 모델. 기본값 `gpt-image-2`. |
| `IMAGE_AI_API_KEY` | 별도 이미지 생성 키를 사용할 때만 지정하는 서버 비밀 값. |
| `SCRIPT_AI_API_KEY` | 별도 이미지 키가 없으면 기존 대본 제작용 키를 재사용합니다. 이미지 모델 이용 권한이 필요합니다. |

일반 로컬 환경의 `OPENAI_API_KEY`도 마지막 대체 입력으로 사용할 수 있습니다. 클라우드에서는 기존
`SCRIPT_AI_API_KEY` 바인딩과 `api.openai.com` HTTPS 접근을 재사용할 수 있으며 새 키가 반드시 필요한 것은 아닙니다.
이 서버 모드의 키를 브라우저나 프로젝트에 반환하지 않습니다. 서버 경로는 `POST /api/image/generate`,
상태 확인은 `GET /api/image/config`입니다. 서버 환경의 키·모델을 바꾸면 서버를 다시 시작합니다. 앱 설정의 직접 연결 키·모델 변경에는 서버 재시작이 필요하지 않습니다.
참조가 있으면 OpenAI Images 편집 API, 없으면 이미지 생성 API를 사용하며 `gpt-image-2`에는 `input_fidelity`를 보내지 않습니다.
종료된 `gpt-image-1`을 새 설정에 사용하지 않습니다. 이 기능을 위한 추가 패키지나 빌드는 필요하지 않습니다.

## 내레이션으로 자동 자막 만들기

1. 미리보기 아래 **음성·자막**을 열어 MP3·WAV 내레이션 파일을 추가하고 사용할 원본 구간과 영상에서 음성이 시작할 시각을 정합니다.
2. 같은 영역의 **음성 분석 · 자동 자막**을 엽니다. 기본 언어는 한국어이며 영어·자동 감지도 선택할 수 있습니다.
3. **분석**을 실행하면 선택한 내레이션 구간만 음성 인식 서비스에 보냅니다. 긴 음성은 최대 300초씩
   나눠 처리하므로 8분 내레이션도 분석할 수 있습니다. 진행 중에는 취소할 수 있습니다.
4. 발화 시각과 문장을 확인한 뒤 **적용**합니다. 적용 전에는 기존 자막을 바꾸지 않으며,
   오류·취소·분석 중 내레이션 변경 시에도 기존 자막을 유지합니다.
5. 미리보기에서 싱크를 확인하고 필요하면 **자막 편집**으로 문구·시작·종료 시각을 보정합니다.
   적용한 자막은 영상 출력에 포함되고 SRT로도 내려받을 수 있습니다.

이 기능은 음성 인식이 반환한 단어별 발화 시간을 묶어 자막을 만듭니다. 단어 시간이 없고 구간 시간이
반환되면 해당 구간 시간을 그대로 사용합니다. 글자 수로 시간을 나눈 기존 대본 자막과는 별도 모드이며,
시간 정보가 없는 인식 결과를 추정 시간으로 대신 표시하지 않습니다. 인식 오탈자나 경계 오차는 직접 확인하세요.

분석한 자막은 원본 음성의 시각을 보관합니다. 같은 내레이션의 앞뒤 구간을 자르거나 영상에서 시작 시각을
옮기면 자막도 그에 맞춰 잘리고 이동합니다. 분석 범위를 넘어 사용 구간을 넓히거나 다른 내레이션으로 교체하면
다시 분석해야 합니다. **자막 편집**에서 수동 적용하면 일반 수동 시간 모드로 바뀌며, 이후 음성 구간 변경에
따라 자동 이동하지 않습니다. 장면이 음성보다 짧으면 음성·자막 끝이 출력되지 않으므로 영상 길이도 확인하세요.

파일 추가나 프로젝트 복원만으로 음성을 업로드하지 않습니다. **분석 버튼을 눌렀을 때만** 선택 구간을
브라우저에서 16kHz 모노 PCM16 WAV로 변환해 OpenAI 음성 인식에 직접 전달합니다. 서버 연결 모드를 선택한 경우 연결한 서버를 거칩니다.
사용하지 않는 원본 구간, BGM과 이미지는 보내지 않습니다. 인식 요청은 사용량에 따른 비용이 발생할 수 있습니다.
원본 음성·적용한 자막·분석 정보는 기존 프로젝트 자동 저장·보관함·파일 포함 백업에 보존됩니다.

## 선택적 음성 분석 서버 설정

OpenAI 직접 연결에서는 앱 설정의 키와 `whisper-1` 모델을 사용합니다. 아래 환경 변수는 서버 연결 모드에만 적용합니다.

| 환경 변수 | 용도 |
| --- | --- |
| `TRANSCRIBE_API_KEY` | 별도 음성 인식 키를 사용할 때만 지정하는 서버 비밀 값. |
| `SCRIPT_AI_API_KEY` | 별도 음성 키가 없으면 기존 대본 제작용 키를 재사용합니다. 음성 인식 모델 권한이 필요합니다. |
| `TRANSCRIBE_MODEL` | 시간 정보를 지원하는 음성 인식 모델. 현재 구현의 기본값·지원값은 `whisper-1`입니다. |

일반 로컬 환경에서는 `OPENAI_API_KEY`가 마지막 대체 입력입니다. 클라우드에서는 기존
`SCRIPT_AI_API_KEY` 바인딩과 `api.openai.com` HTTPS 허용을 재사용합니다. 이 서버 운영용 키를 프런트엔드로 반환하거나 프로젝트에
저장하지 않으며 서버 설정을 바꾸면 다시 시작합니다. 상태 확인은 `GET /api/transcript/config`,
분석은 `POST /api/transcript/analyze`입니다. 추가 패키지나 빌드는 필요하지 않습니다.

현재 `whisper-1`의 단어·구간 타임스탬프를 사용합니다. 공식 API 명세에는 이 모델의 종료 예정일이

검증해 교체해야 합니다. 텍스트만 반환하는 모델을 이름만 바꿔 연결하면 싱크 자막을 만들 수 없습니다.

## 편집 편의기능

1. **장면 복제·설정 복사**: 선택한 장면을 복제하거나 움직임·이미지 맞춤·구도 설정을 복사해 붙여넣습니다.
2. **여러 장면 일괄 수정**: 체크박스, Ctrl/Cmd 클릭, Shift 클릭으로 여러 장면을 선택해 시간·움직임·맞춤을 한꺼번에 바꿉니다.
3. **다시 실행·단축키**: 되돌린 편집을 다시 실행하고 복제·삭제·탐색을 키보드로 조작합니다.
4. **SRT 자막 편집**: ‘자막 편집’에서 문구·시작·종료 시간을 수정하거나 전체 시간을 ±초 이동합니다. 대본 자막을 적용하면 수동 시간 모드로 전환되며 ‘대본 자막으로’로 돌아갈 수 있습니다.
5. **타임라인 길이 조절**: 장면 오른쪽 경계를 끌어서 길이를 바꾸거나 경계 버튼에 초점을 두고 ←/→로 0.1초씩, Shift와 함께 1초씩 조절합니다. 타임라인 확대도 지원합니다.
6. **음성 파형**: 내레이션 파형을 보고 클릭해 재생 위치를 이동합니다. 파형은 자른 원본 구간을 반영합니다.
7. **이미지 위치·크롭**: 장면 설정의 이미지 미리보기를 끌거나 가로·세로 위치 값을 조절해 구도를 정합니다.
8. **확대·이동 세부 설정**: 시작·종료 위치와 확대 배율을 지정하는 사용자 지정 움직임을 제공합니다.
9. **자막 스타일 프리셋**: 글꼴·색상·테두리·배경·위치·크기를 조절하고 이름을 붙여 재사용합니다.
10. **오디오 구간·음량**: 원본 파일의 시작·끝 시간, 영상에서 음성이 시작할 시각과 내레이션 음량을 조절합니다. 끝을 비우면 파일 끝까지 사용합니다.
11. **BGM 페이드·자동 음량 조절**: 영상 시작·끝 페이드를 적용하고 내레이션이 들리는 동안 음악을 낮춥니다.
12. **장면 분할·합치기**: 재생 위치에서 장면을 나눕니다. 합치기는 같은 이미지를 사용하는 연속 장면에만 적용합니다.
13. **구간 반복 미리보기**: A–B 시각을 지정하거나 선택 장면을 반복해 자막·음성을 확인합니다.
14. **프로젝트 보관함·복제**: 브라우저 안에 여러 작업을 보관하고 썸네일로 열거나 복제합니다. 새 프로젝트나 다른 프로젝트를 열 때 현재 작업도 먼저 보관합니다.
15. **인트로·아웃트로 템플릿**: 제목·보조 문구·색상·로고로 이미지 장면을 만들고 앞이나 뒤에 추가합니다. 맨 앞에 추가하면 내레이션 시작과 SRT·음성 분석 자막도 그 길이만큼 뒤로 이동합니다.
16. **현재 화면 PNG 저장**: 미리보기 화면을 이미지로 내려받아 썸네일이나 표지로 사용합니다.
17. **음성 분석 자막**: 내레이션의 실제 발화 시간을 인식해 자막을 만든 뒤 확인·적용합니다. 원본 구간과 음성 시작 시각 변경을 반영합니다.
18. **분야별 작업 공간**: 분야 추가·이름 변경·순서 조절·보관·다시 열기로 작업을 구분하고 분야마다 대본·자료·미디어를 별도로 이어갑니다.

자막 시간의 전체 이동은 시작 시각이 음수가 되는 경우 적용되지 않습니다.
SRT 자막은 장면 시간과 별도로 관리되므로 장면 순서나 길이를 바꾼 뒤에는 싱크를 확인하세요.
배경음악은 선택한 원본 구간만 반복하며, 음성 길이에 장면 맞추기도 자른 내레이션 길이와 영상 내 시작 시각을 반영합니다.
음악 자동 음량 조절은 소리 크기(RMS)를 기준으로 작동하며 음성 인식 기능은 아닙니다.

자막·제목 템플릿 설정은 이 브라우저에 저장됩니다. 제목 템플릿의 로고는 추가한 이미지 장면에 포함되지만,
저장한 템플릿 설정에는 포함되지 않으므로 다음에 사용할 때 다시 선택합니다.

## 키보드 조작

입력칸·선택 메뉴·버튼·접힌 도구 제목에 초점이 있거나 대화상자가 열린 동안에는 아래 전역 단축키가 적용되지 않습니다.
버튼에 초점이 있을 때 Space는 그 버튼을 실행하며, 접힌 도구 제목의 Enter·Space는 해당 영역을 열고 닫습니다.
Mac에서는 Ctrl 대신 Cmd를 사용합니다.

| 단축키 | 동작 |
| --- | --- |
| Ctrl/Cmd + Z | 되돌리기 |
| Ctrl/Cmd + Shift + Z 또는 Ctrl/Cmd + Y | 다시 실행 |
| Ctrl/Cmd + D / A | 장면 복제 / 모든 장면 선택 |
| Ctrl/Cmd + C / V | 장면 설정 복사 / 붙여넣기 |
| Delete / Backspace | 선택 장면 삭제 |
| Space | 재생·일시정지 |
| ← / → | 재생 위치 0.1초 이동, Shift와 함께 1초 이동 |
| Home / End | 처음 / 끝으로 이동 |
| Page Up / Page Down | 이전 / 다음 장면 선택 |

## 의도적인 범위와 제한

- 음성은 CLOVA API로 생성하거나 직접 준비한 MP3·WAV로 가져옵니다. 이미지는 직접 가져오거나 선택 기능인 고정 레퍼런스 생성으로 준비할 수 있습니다. GPT용 제작 요청문 복사 도우미도 제공합니다. 유료 동영상 생성 API는 추가하지 않습니다.
- 일반 대본 자막 시간은 글자 수에 따른 추정입니다. 별도 음성 분석 자막은 인식 서비스의 발화 시간을 사용하며, SRT는 가져온 시간을 유지합니다.
- 영상 내보내기는 Canvas + Web Audio + MediaRecorder를 사용하는 실시간 출력입니다. 영상 길이만큼 시간이 필요하고, 탭이 숨겨지면 출력이 중단됩니다.
- IndexedDB에 분야별 현재 프로젝트와 원본 Blob을 자동 저장하고, 공유 보관함에 여러 프로젝트를 별도로 저장합니다. 기기 간 동기화는 하지 않으며, 현재 프로젝트의 파일 포함 JSON 백업을 지원합니다. 브라우저 데이터를 지우면 분야·보관함·프리셋도 지워집니다.
- 이미지 없는 장면의 출력은 차단합니다. 영상보다 긴 내레이션은 끝이 잘리므로 경고합니다.
- 미디어 합계 180MiB, 백업 250MiB, 장면 200개, 프로젝트 최대 60분을 검증합니다. 짧은 설정 소개 영상 제작을 기본 사용 범위로 합니다.
