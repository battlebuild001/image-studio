# BTH BLKOUT Image Studio

브라우저에서 GPT 이미지와 클로바 음성 파일을 조립하는 영상 편집기. 외부 이미지·음성·영상 생성 API와 외부 런타임 의존성을 사용하지 않습니다.

소스 저장소: https://github.com/battlebuild001/image-studio

## 실행 및 개발

Node.js 22 이상이면 실행할 수 있습니다. 별도 패키지 설치, 빌드, API 키가 필요하지 않습니다.

```bash
git clone https://github.com/battlebuild001/image-studio.git
cd image-studio
npm start
```

브라우저에서 http://127.0.0.1:4173/ 을 엽니다. `index.html`을 파일로 직접
여는 대신 이 서버를 사용합니다. 서버는 `dist/`만 제공합니다.

```bash
npm test
```

다른 호스트나 포트가 필요할 때:

```bash
npm start -- --host 0.0.0.0 --port 4173
```

## 배포

- 기존 서비스: https://bth-blkout-image-studio.hebi-cogitox.chatgpt.site/
- 정적 배포 디렉터리: `dist/`.
- `dist/`는 빌드 산출물이 아니라 직접 수정하는 원본 소스입니다.
- `.openai/hosting.json`은 기존 Sites 프로젝트를 가리킵니다.
- GitHub 커밋만으로 기존 서비스가 자동 배포되지는 않습니다. 서비스를
  변경하려면 Sites에서 같은 프로젝트에 새 버전을 배포해야 합니다.

## 사용 흐름

1. 대본을 붙여넣어 장면을 만들거나 이미지를 먼저 추가합니다.
2. PNG/JPG/WebP 등을 붙여넣기, 드래그, 파일 선택으로 가져옵니다. 빈 장면부터 채우며 명시적인 교체 버튼도 있습니다.
3. 클로바에서 내려받은 MP3/WAV를 넣으면 실제 음성 길이에 장면 시간을 배분합니다.
4. 장면별 시간·자막·확대/축소·좌우이동·이미지 맞춤을 조절합니다. 정확한 자막 파일은 SRT로 가져옵니다.
5. 미리보기 후 MP4 또는 WebM으로 내보냅니다. 형식은 브라우저가 실제로 지원하는 것만 선택할 수 있습니다.

## 의도적인 범위와 제한

- 음성 생성과 AI 이미지 생성은 사용자가 기존 서비스에서 준비합니다. GPT용 제작 요청문 복사 도우미를 제공합니다.
- 일반 대본 자막 시간은 글자 수에 따른 추정입니다. 음성 인식이나 강제 정렬 결과로 표시하지 않습니다. SRT는 원래 시간을 유지합니다.
- 영상 내보내기는 Canvas + Web Audio + MediaRecorder를 사용하는 실시간 출력입니다. 영상 길이만큼 시간이 필요하고, 탭이 숨겨지면 출력이 중단됩니다.
- IndexedDB에 프로젝트와 원본 Blob을 자동 저장합니다. 기기 간 동기화는 하지 않으며, 파일 포함 JSON 백업을 지원합니다.
- 이미지 없는 장면의 출력은 차단합니다. 영상보다 긴 내레이션은 끝이 잘리므로 경고합니다.
- 미디어 합계 180MiB, 백업 250MiB, 장면 200개, 프로젝트 최대 60분을 검증합니다. 짧은 설정 소개 영상 제작을 기본 사용 범위로 합니다.

## 구현

- `dist/main.js`: 편집 UI, 미디어 입력, 재생, 작업 흐름
- `dist/project.js`: 프로젝트 검증, SRT, 시간 배분, 백업, IndexedDB
- `dist/engine.js`: 캔버스 렌더, 자막, 전환, 음성 믹스, 실제 영상 출력
- `dist/index.html`, `dist/style.css`: 반응형 한국어 편집 화면

정적 배포 폴더는 `dist/`입니다. 테스트: `npm test`.
