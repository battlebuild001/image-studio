  1. 대본과 이미지를 넣어요.

    ‘대본에서 장면 만들기’로 장면을 나눈 뒤, GPT에서 복사한 이미지를 Ctrl+V로 붙여넣으세요. 파일 드래그와 여러 장 업로드도 가능해요.

  2. 내레이션과 자막을 맞춰요.

    MP3·WAV 파일을 넣고 ‘음성 길이에 장면 맞추기’를 누르세요. ‘음성 분석 · 자동 자막’으로 발화 시간을 인식하고, 결과를 확인해 적용하세요. 자막 편집과 SRT 가져오기도 가능해요.

  3. 미리보고 영상을 저장해요.

    장면마다 확대·이동, 표시 시간, 자막을 조절한 뒤 내보내세요. MP4 지원 여부는 브라우저에 따라 달라지며, WebM도 제공해요.

작업은 이 브라우저에 자동 저장돼요.

다른 기기로 옮기거나 브라우저 데이터를 지우기 전에는 ‘백업 저장’으로 이미지와 음성이 포함된 프로젝트 파일을 받아두세요. 일반 영상 편집은 이미지·음성을 브라우저에서 처리해요. 자료로 대본 제작을 실행하면 입력 자료의 텍스트가, 레퍼런스로 이미지 제작을 실행하면 선택한 기준 이미지와 제작 문구가 AI 서비스로 전송돼요. 음성 분석을 실행하면 현재 자르기 범위의 내레이션과 인식 참고어가 음성 인식 서비스로 전송돼요.
