YouTube 연결 개인정보 안내

적용일: 2026년 11월 5일

CONTENT STUDIO의 YouTube 기능은 사용자가 선택한 영상·썸네일 이미지와 제목·설명·태그를 연결한 YouTube 채널에 올립니다. Google Identity Services와 YouTube API 서비스를 이용하며, 업로드는 브라우저에서 Google로 직접 전송합니다.

연결에 사용하는 정보

  • 공개 Google OAuth 클라이언트 ID는 이 브라우저의 사이트 데이터에 저장합니다. 클라이언트 보안 비밀은 입력받지 않습니다.
  • 연결된 채널의 이름·식별자와 임시 접근 토큰, 중단한 업로드의 재개 정보는 현재 페이지 메모리에서 사용합니다. 접근 토큰과 업로드 세션 주소는 프로젝트·백업·보관함에 넣거나 사이트 데이터에 저장하지 않습니다.
  • 기본 연결은 영상 업로드(youtube.upload)와 연결할 채널의 읽기(youtube.readonly) 권한을 요청합니다. 사용자가 별도의 재생목록 추가 권한 연결을 실행할 때만 youtube.force-ssl 권한을 추가로 요청하고 Google 동의를 받습니다. Google 계정 비밀번호는 이 앱이 입력받거나 저장하지 않습니다.

영상과 설명란의 전송

‘유튜브 업로드’를 누르거나, 제목·설명·채널을 확인해 ‘자동 업로드 준비’를 실행한 뒤 다음 영상을 내보내면 선택한 영상 파일과 게시 정보를 Google에 보냅니다. 자동 업로드 준비는 한 번만 사용하며 새로고침하면 해제됩니다. 공개 상태·아동용 여부·사실처럼 보이는 AI·합성 콘텐츠 여부는 사용자가 선택합니다.

검색용 태그는 YouTube의 별도 게시 정보이며 설명란의 #해시태그와 구분합니다. 기본으로 켜진 해시태그 표시 옵션은 사용자가 적용한 미니어처 게임 태그 중 최대 5개를 설명 입력란에 반영합니다. 태그 적용·표시 옵션 변경·명시적 반영·설명 생성·게시 자료 가져오기에서 실제 설명을 확인할 수 있으며, 창을 여는 것만으로 기존 설명을 바꾸거나 업로드 순간에 문구를 추가하지 않습니다. 직접 작성한 해시태그는 보존하고 앱이 마지막에 넣은 정확한 해시태그 행만 갱신합니다. 이미 업로드한 영상의 설명을 자동 수정하지 않습니다.

예약 공개를 선택하면 확인한 공개 시각을 Google에 전달하고 영상을 미리 비공개로 전송합니다. 전송이 완료된 영상은 브라우저를 닫아도 YouTube가 지정 시각에 공개합니다. 영상 출력과 파일 전송이 끝나기 전에는 브라우저를 열어 두어야 합니다. 예약의 UTC 시각과 선택한 시간대, 회차별 시간표 및 Google 응답에서 예약이 확인됐는지를 프로젝트·백업·업로드 기록에 보관합니다. 이 기능은 추가 Google 권한이나 서버에 저장한 접근 토큰을 요구하지 않습니다.

썸네일을 선택한 경우 검토한 이미지 파일을 영상 업로드가 끝난 뒤 같은 영상에 추가로 전송합니다. 썸네일 전송이 실패해도 이미 업로드한 영상은 유지되며, 사용자가 선택하면 해당 영상의 썸네일만 다시 전송합니다. 전송용 이미지와 선택 상태는 현재 페이지 메모리에만 두고, 편집용 썸네일 문구·레이아웃 설정은 프로젝트에 보관합니다.

‘내 재생목록 불러오기’를 실행하면 기존 읽기 권한으로 현재 연결한 채널이 만든 재생목록을 Google에서 조회합니다. 창을 여는 것만으로 조회하지 않습니다. 사용자가 목록을 선택하고 추가 권한에 동의한 경우, 영상 업로드 완료 기록을 저장한 뒤 해당 영상이 목록에 있는지 확인하고 필요한 경우에만 추가합니다. 추가 실패·불확실 상태에서 다시 확인해도 같은 영상의 재생목록 항목만 조회·추가하며 영상 파일을 다시 업로드하지 않습니다. 재생목록을 새로 만들거나 삭제하지 않으며, 이 선택은 쇼츠·드라마 시리즈 업로드에 적용하지 않습니다.

이 앱의 웹 호스팅 서버는 YouTube 업로드를 중계하거나 사용자 영상을 보관하지 않습니다. Google과 YouTube는 전송받은 정보를 각 서비스의 약관과 개인정보처리방침에 따라 처리합니다. 앱의 다른 AI 작성 기능을 별도로 실행하면 해당 기능에 설정한 제공자에게 자료를 보냅니다.

영상 자동 검수와 숫자·연도 비교는 기기에서 실행합니다. AI 내용 비교를 실행하면 참고 원문과 대본을, AI 편집안을 요청하면 편집 요청·장면 대본·설정을, AI 쇼츠 구도 분석을 실행하면 선택한 장면의 축소 이미지와 캡션을 설정한 AI 제공자에게 보냅니다. 창을 여는 것만으로 전송하지 않으며, 이 기능들은 Google 계정 접근 토큰이나 YouTube 업로드 권한을 사용하지 않습니다. 검사 결과와 적용 전 편집안은 현재 페이지 메모리에서 사용하고, 적용한 편집·저장한 쇼츠 구도는 프로젝트에 보관합니다.

브라우저에 남는 자료

사용자가 작성한 업로드 제목·설명·태그·공개 설정과 최근 업로드 기록(영상 링크·제목·채널·시각·파일 이름·크기)은 프로젝트와 함께 이 브라우저에 저장합니다. 선택한 재생목록의 이름·식별자·소유 채널과 해당 영상의 추가 처리 상태·시각·확인된 항목 식별자도 보관합니다. 프로젝트 백업을 만들면 해당 게시 정보도 포함됩니다. 재생목록 권한의 승인 상태나 접근 토큰은 저장하지 않습니다. 영상 원본과 편집용 미디어의 저장 방식은 기존 편집기와 같습니다. 앱은 YouTube 연결 자료를 판매하거나 광고 목적으로 공유하지 않습니다.

직접 저장한 미니어처 게임 태그 프리셋의 이름과 태그 목록은 같은 브라우저의 사이트 데이터에 별도로 보관합니다. 프리셋의 저장·조회만으로 Google에 전송하지 않으며, 태그 프리셋에서 개별 수정·삭제할 수 있습니다. 프리셋 정의는 프로젝트 백업에 포함하지 않습니다.

영상 설명의 길이, 제작 지원 안내 포함 여부와 해시태그 표시 여부는 프로젝트·백업에 보관합니다. 앱이 붙인 해시태그 행을 정확히 갱신하기 위한 표시도 게시 자료와 업로드 초안에 각각 보관합니다. 제작 지원 안내는 사용자가 선택했을 때만 설명 마지막에 추가하며, 실제 업로드 시 확인한 설명과 함께 Google에 전송합니다.

연결 해제와 삭제

앱의 ‘연결 해제’로 현재 접근 권한을 철회하고 메모리의 연결·재개 정보를 지울 수 있습니다. 연결 해제 시 앱에 저장된 모든 프로젝트·분야 탭·보관함의 YouTube 업로드 기록과 재생목록 선택·추가 처리 기록도 지웁니다. ‘이 앱의 업로드 기록 지우기’로 별도로 삭제할 수도 있습니다. 직접 작성한 게시 초안과 편집용 미디어는 유지합니다. 앱 밖에 내려받은 백업 파일은 사용자가 직접 관리하고 삭제해야 합니다. Google 계정의 연결 관리에서도 권한을 철회할 수 있습니다. 브라우저의 이 사이트 데이터 삭제로 로컬 설정과 프로젝트를 지울 수 있으므로 필요한 백업은 먼저 보관하세요.

전송을 중지하거나 연결을 해제하거나 이 앱의 로컬 자료를 지워도 YouTube가 이미 받은 영상·재생목록·추가된 항목은 삭제되지 않으며, 완료된 영상의 예약 공개도 취소되지 않습니다. 업로드한 영상의 예약 변경·취소, 공개 상태 변경과 삭제 및 재생목록 관리는 YouTube Studio에서 할 수 있습니다.

외부 서비스 약관과 문의

이 기능을 이용할 때 YouTube 서비스 약관이 적용됩니다. Google 개인정보처리방침도 확인할 수 있습니다. 앱 관련 문의는 프로젝트 문의 페이지를 이용하세요. 문의에 접근 토큰·API 키·계정 비밀번호를 포함하지 마세요.
